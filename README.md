# Sherry Mae L. Flores: BSIT Portfolio

My personal portfolio website for the BSIT Industry-Ready Portfolio project at Datamex College of Saint Adeline.

**Live site:** https://floressherrymae01-netizen.github.io/portfolio/

## Sections
Home · Profile · Technical Skills · Projects · Problem-Solving · Employability · Resume · Certificates · GitHub · Contact · Reflection

## Features
- Dark mode button
- Skills filter
- Certificate viewer (click to enlarge)
- Moving purple background
- Contact form with validation
- Works on phone and desktop

## Built with
HTML · CSS · JavaScript · Bootstrap 5 · Bootstrap Icons

## Folder structure
```
index.html     page content
css/style.css  design
js/script.js   interactive features
assets/        images, certificates, and resume
```
